# A/B Testing at Scale: Power, Sequential Testing, and Practical Pitfalls

Code and outputs for my Data Science & Analytics blog (Advanced Blog Topics, Topic 9).

- `ab_testing_at_scale.ipynb` – full mini-experiment (sample size, power, peeking simulation, Pocock / O'Brien–Fleming boundaries, effect-size ablation, multiple comparisons). Synthetic data, fixed seeds – rerun to reproduce every number.
- `diagram.py` – draws Figure 0 (workflow diagram).
- `results_*.csv` – result tables used in the blog.
- `figures/` – all charts and equation images.
- `AB_Testing_at_Scale_Blog.pdf` – the blog as a PDF.

**Run:** `pip install numpy scipy pandas statsmodels matplotlib jupyter` then open the notebook and Run All.
